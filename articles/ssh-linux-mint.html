SSH w Linux Mint – zdalne zarządzanie systemem

Jak skonfigurować SSH w Linux Mint, połączyć się z komputerem przez terminal i rozpocząć zdalne zarządzanie własnym systemem.

1. Czym jest SSH?

SSH, czyli Secure Shell, to protokół umożliwiający bezpieczne zarządzanie zdalnym komputerem za pomocą połączenia sieciowego.

Administrator może wykonywać polecenia, zarządzać plikami, instalować oprogramowanie i kontrolować system bez fizycznego dostępu do urządzenia.

SSH jest szczególnie przydatne w:

  • administracji serwerami Linux,
  • budowie homelabów,
  • zarządzaniu komputerami bez monitora,
  • automatyzacji zadań,
  • zdalnej administracji przez VPN.
SSH szyfruje komunikację pomiędzy klientem i serwerem. Dzięki temu dane przesyłane przez połączenie nie są wysyłane w postaci zwykłego tekstu.

2. Jak działa połączenie SSH?

SSH wykorzystuje model klient–serwer. Jeden komputer inicjuje połączenie, a drugi je obsługuje.

Klient SSH

Komputer, z którego wykonujemy połączenie. W Linux Mint klient SSH jest zwykle dostępny od razu po instalacji systemu.

Serwer SSH

Komputer, na którym działa usługa OpenSSH Server i który przyjmuje połączenia.

Schemat połączenia:

┌──────────────────────┐
│   Klient SSH         │
│   Linux / Terminal   │
└──────────┬───────────┘
           │
           │ SSH
           │ TCP port 22
           ▼
┌──────────────────────┐
│   Serwer SSH         │
│   Linux Mint         │
│   OpenSSH Server     │
└──────────────────────┘

3. Instalacja OpenSSH Server

Na komputerze, którym chcemy zarządzać zdalnie, otwieramy terminal.

Krok 1

Aktualizacja listy pakietów:

sudo apt update
Krok 2

Instalacja serwera SSH:

sudo apt install openssh-server
Krok 3

Sprawdzenie statusu usługi:

sudo systemctl status ssh

Jeżeli usługa nie jest uruchomiona, można ją włączyć: 

sudo systemctl enable --now ssh

Polecenie uruchamia SSH od razu i ustawia automatyczne uruchamianie usługi podczas startu systemu.

4. Sprawdzenie adresu IP serwera

Aby połączyć się z komputerem w sieci lokalnej, potrzebujemy jego adresu IP. 

hostname -I

Przykładowy wynik: 

192.168.1.100
Uwaga: adres 192.168.1.100 jest przykładowy. W rzeczywistości należy użyć adresu IP swojego serwera. Adres może się zmieniać w zależności od konfiguracji sieci.

5. Pierwsze połączenie SSH

Na drugim komputerze otwieramy terminal. Następnie wpisujemy: 

ssh nazwa_uzytkownika@192.168.1.100

Przykład: jeśli użytkownik na serwerze nazywa się admin, polecenie będzie wyglądało tak: 

ssh admin@192.168.1.100

Przy pierwszym połączeniu SSH może zapytać, czy zaufać kluczowi hosta. 

Are you sure you want to continue connecting?

Po zweryfikowaniu tożsamości serwera można zaakceptować klucz, wpisując: 

yes

Następnie system poprosi o hasło użytkownika na komputerze zdalnym.

Po poprawnym uwierzytelnieniu uzyskujemy dostęp do terminala zdalnego komputera.

6. Przydatne polecenia SSH

Polecenie Zastosowanie
ssh user@host Połączenie z serwerem
exit Zakończenie sesji
whoami Sprawdzenie użytkownika
hostname Wyświetlenie nazwy komputera
uptime Informacja o czasie pracy systemu
ip addr Informacje o interfejsach sieciowych
sudo systemctl status ssh Status usługi SSH

7. Logowanie za pomocą klucza SSH

Klucze SSH umożliwiają uwierzytelnianie bez wpisywania hasła użytkownika przy każdym połączeniu. Jest to wygodne rozwiązanie dla administratorów.

Krok 1. Generowanie klucza

Na komputerze-kliencie wykonujemy:

ssh-keygen -t ed25519

Program utworzy parę kluczy:

  • id_ed25519 – klucz prywatny,
  • id_ed25519.pub – klucz publiczny.
Klucz prywatny należy chronić. Nie wysyłamy go innym osobom i nie publikujemy w Internecie.

Krok 2. Kopiowanie klucza na serwer

ssh-copy-id user@192.168.1.100

Polecenie kopiuje klucz publiczny do konfiguracji użytkownika na serwerze.

Krok 3. Połączenie

ssh user@192.168.1.100

Jeżeli konfiguracja jest poprawna, uwierzytelnianie powinno odbywać się przy użyciu klucza.

8. Konfiguracja SSH

Główny plik konfiguracyjny serwera SSH znajduje się w lokalizacji: 

/etc/ssh/sshd_config

Otwieramy go za pomocą edytora Nano:

sudo nano /etc/ssh/sshd_config

Po wprowadzeniu zmian należy sprawdzić konfigurację: 

sudo sshd -t

Jeżeli nie pojawią się błędy, można przeładować usługę: 

sudo systemctl reload ssh
Nie zmieniaj ustawień uwierzytelniania bez wcześniejszego sprawdzenia, czy masz działające połączenie alternatywne. Błędna konfiguracja może odciąć dostęp do serwera.

9. Podstawowe bezpieczeństwo

  • Używaj silnych haseł.
  • Preferuj klucze SSH z odpowiednio chronionym kluczem prywatnym.
  • Regularnie aktualizuj system.
  • Nie udostępniaj klucza prywatnego.
  • Nie wystawiaj SSH bezpośrednio do Internetu bez przemyślanej konfiguracji.
  • Ogranicz dostęp do serwera do zaufanych urządzeń i sieci.

Aktualizacja systemu

sudo apt update
sudo apt upgrade

Firewall UFW

Jeżeli korzystasz z UFW, możesz sprawdzić jego status: 

sudo ufw status

Włączenie firewalla wymaga ostrożności. Przed aktywacją upewnij się, że reguły pozwalają na połączenia SSH. 

sudo ufw allow OpenSSH

Dopiero po sprawdzeniu reguł można rozważyć aktywację: 

sudo ufw enable

10. Rozwiązywanie problemów

Connection refused

Serwer odrzuca połączenie. Sprawdź, czy SSH działa: 

sudo systemctl status ssh

Connection timed out

Możliwe przyczyny:

  • nieprawidłowy adres IP,
  • brak połączenia sieciowego,
  • blokada przez firewall,
  • serwer jest wyłączony.

Permission denied

Sprawdź nazwę użytkownika, hasło oraz konfigurację kluczy SSH.

Sprawdzenie portu

sudo ss -tlnp | grep ssh

Domyślny port SSH to TCP 22.

11. Podsumowanie

SSH jest jednym z podstawowych narzędzi administracji systemami Linux. Pozwala zarządzać komputerem zdalnie, bez potrzeby korzystania z lokalnego monitora i klawiatury.

Opanowanie SSH stanowi fundament dalszej pracy z serwerami, homelabem, automatyzacją oraz administracją infrastruktury IT.

Najważniejsze: instalacja OpenSSH Server, sprawdzenie adresu IP, pierwsze połączenie, klucze SSH i bezpieczna konfiguracja.

Kolejnym krokiem może być wykorzystanie SSH do zarządzania serwerem Linux Mint przez Tailscale, bez wystawiania portu SSH bezpośrednio do Internetu.

SSH w Linux Mint

Zdalne zarządzanie systemem z terminala

Linux SSH Terminal Homelab

SSH (Secure Shell) to jeden z podstawowych protokołów wykorzystywanych przez administratorów systemów Linux. Pozwala na bezpieczne zarządzanie komputerem zdalnym, wykonywanie poleceń oraz przesyłanie plików.

SSH umożliwia pracę na komputerze bez konieczności fizycznego dostępu do jego klawiatury, myszy czy monitora.

1. Jak działa SSH?

Połączenie SSH odbywa się pomiędzy komputerem klienckim a komputerem, na którym działa serwer SSH. Komunikacja jest szyfrowana.

Przykładowa architektura połączenia:


┌────────────────────┐
│  Komputer klienta │
│  Linux / Windows  │
└─────────┬──────────┘
          │
          │ SSH — port 22
          │
┌─────────▼──────────┐
│  Komputer zdalny  │
│  Linux Mint       │
│  OpenSSH Server   │
└───────────────────┘

2. Instalacja serwera SSH w Linux Mint

Linux Mint może korzystać z serwera OpenSSH. Aby go zainstalować, otwórz terminal i wykonaj: 

sudo apt update
sudo apt install openssh-server

Podczas instalacji system może poprosić o hasło użytkownika posiadającego uprawnienia administracyjne.

3. Sprawdzenie działania usługi

Po instalacji sprawdź status serwera SSH:

sudo systemctl status ssh

Jeśli usługa jest aktywna, w wyniku powinien pojawić się status: 

Active: active (running)

Jeżeli usługa nie działa, możesz ją uruchomić:

sudo systemctl start ssh

Aby uruchamiała się automatycznie po starcie systemu:

sudo systemctl enable ssh

4. Sprawdzenie adresu IP komputera

Aby połączyć się z komputerem w sieci lokalnej, potrzebujesz jego adresu IP. 

hostname -I

Przykładowy wynik: 

192.168.1.100
Powyższy adres jest przykładowy. W Twojej sieci komputer może mieć inny adres IP.

5. Połączenie z komputerem zdalnym

Na drugim komputerze otwórz terminal i wpisz: 

ssh nazwa_uzytkownika@192.168.1.100

Zastąp nazwę użytkownika oraz adres IP właściwymi danymi komputera docelowego.

Przy pierwszym połączeniu SSH może poprosić o potwierdzenie autentyczności hosta. Po sprawdzeniu informacji wpisz: 

yes

Następnie podaj hasło użytkownika komputera zdalnego. Podczas wpisywania hasła terminal nie wyświetla znaków.

6. Podstawowe polecenia SSH

Połączenie z serwerem

ssh user@192.168.1.100

Połączenie z niestandardowym portem

ssh -p 2222 user@192.168.1.100

Zakończenie sesji

exit

7. Przesyłanie plików przez SCP

SSH umożliwia również przesyłanie plików. Do tego celu można wykorzystać narzędzie SCP.

Przykład przesłania pliku na komputer zdalny:

scp dokument.txt user@192.168.1.100:~/

Przykład pobrania pliku z komputera zdalnego: 

scp user@192.168.1.100:~/dokument.txt .

8. SSH w środowisku Homelab

SSH jest szczególnie przydatne podczas budowy własnego środowiska Homelab.

  • Administracja serwerami bez monitora.
  • Zdalne zarządzanie Linux Mint.
  • Obsługa Raspberry Pi i mini-PC.
  • Automatyzacja zadań administracyjnych.
  • Przesyłanie plików pomiędzy urządzeniami.
  • Praca z serwerami znajdującymi się w innym miejscu.

9. Bezpieczeństwo

Nie udostępniaj serwera SSH bezpośrednio do Internetu bez odpowiedniej konfiguracji zabezpieczeń.

Warto pamiętać o kilku zasadach:

  • Używaj silnych haseł.
  • Aktualizuj system i pakiety.
  • Rozważ uwierzytelnianie kluczami SSH.
  • Ogranicz dostęp do serwera do zaufanych urządzeń.
  • Nie udostępniaj prywatnych kluczy SSH.

Podsumowanie

SSH jest podstawowym narzędziem w pracy z systemami Linux. Pozwala na zdalne wykonywanie poleceń, zarządzanie serwerami oraz przesyłanie plików.

Opanowanie SSH to jeden z pierwszych kroków w kierunku administracji systemami Linux, budowy Homelab i zarządzania własną infrastrukturą IT.

Praktyka: Najlepszym sposobem nauki SSH jest skonfigurowanie połączenia pomiędzy dwoma własnymi komputerami lub urządzeniami w sieci.
